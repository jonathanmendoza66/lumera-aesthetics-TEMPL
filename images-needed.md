## File Format Notes
- Hero/banner images: JPG, high quality, aim for 150-200KB after compression
- Team portraits: JPG, ~100-150KB each
- Gallery results: JPG, ~80-120KB each
- Logo/favicon: PNG with transparent background, <50KB
- All images should have consistent warm color grading (slightly warm white balance, soft contrast)
